# Imadeoconvert 1.18.0-rc.1

首个公开 Windows 预览版，提供图片和视频批量转换。

## 下载与安装

- **`Imadeoconvert-1.18.0-rc.1-windows-x64-setup.exe`**：Windows 10/11 x64 安装包。安装到当前用户目录，无需管理员权限，提供开始菜单入口、可选桌面快捷方式和卸载功能。
- **`Imadeoconvert-1.18.0-rc.1-windows-x64.zip`**：便携版。完整解压后运行 `Imadeoconvert.exe`，保留 `_internal` 和 `tools` 目录。
- `.sha256` 文件用于校验下载完整性；应用源码可从此版本标签下载。

两种分发方式均包含 Python 运行时及 FFmpeg/FFprobe，无需另行安装。转换在本机完成，不上传媒体。可在设置中关闭 GitHub 更新检查。

## 本版功能

- 图片批量格式转换、尺寸调整、SVG 栅格化及图片对比。
- 视频输出 MP4/MKV（H.264 + AAC）、WebM（VP9 + Opus）；画质、速度、最大高度及静音设置。
- 媒体信息、转换进度、取消、失败重试、系统播放器打开结果。
- 源文件保护、重名输出编号、临时写入与完成校验。
- 统一 Imadeoconvert 名称，迁移旧 ImadeoCovert 配置，保留原文件；卸载保留用户设置及用户创建的文件。
- 修复 RC 版本到正式版的更新比较。

## 验证与当前限制

发布前执行源码回归、便携 EXE 自检以及安装—运行—卸载测试，覆盖真实图片编码、MP4/MKV/WebM、无音轨输入、取消和用户文件保留。安装测试在现有 Windows 主机的独立目录进行，清除 Conda/Python 环境并限制 PATH；尚未完成全新 Windows / Sandbox 验收。

当前仅支持普通 SDR 视频，输出为 8-bit；HDR、透明视频会被拒绝。保留主视频与默认/第一条音轨，不保留字幕、章节及额外轨道。安装包未做代码签名，Windows 可能提示发布者未知。

本版标记为 **Pre-release**。原作者版权、应用 GPL 许可及第三方许可随包提供；第三方原生依赖的完整对应源码材料核对仍未完成，`release-policy.json` 保持 `pending`，本次公开预览不代表该项审查已完成。此项及干净系统验收继续列为正式版待办。
